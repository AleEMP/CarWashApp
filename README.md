# CarWash AQP

**CarWash AQP** es una aplicación móvil orientada a facilitar la búsqueda y comparación de centros de lavado de vehículos en Arequipa.

El proyecto busca solucionar la dificultad que tienen los conductores para encontrar lavaderos cercanos y conocer sus precios, servicios y horarios antes de acudir al establecimiento.

## Objetivo

Desarrollar una plataforma que conecte a conductores con centros de lavado de vehículos, permitiendo comparar opciones y elegir la más conveniente según su ubicación, tipo de vehículo y necesidades.

## Funcionalidades principales

- **Mapa interactivo:** Visualización de centros de lavado cercanos.
- **Comparación de precios:** Consulta de tarifas según el tipo de vehículo.
- **Información de establecimientos:** Servicios, horarios, ubicación y comodidades.
- **Reseñas y calificaciones:** Opiniones de otros usuarios.
- **Gestión de negocios:** Los propietarios podrán administrar la información de sus establecimientos.

## Tecnologías

- **Aplicación móvil:** React Native, Expo y TypeScript.
- **Base de datos y autenticación:** Supabase (PostgreSQL).
- **Mapas y geolocalización:** Google Maps y Expo Location.
